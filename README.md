# 彩票助手

一款面向彩票信息查询、模拟投注与轻量娱乐需求设计的 Android App，由个人独立完成产品规划、交互设计、功能实现、测试与版本迭代。

> 彩票开奖结果具有随机性。本软件仅用于数据记录、辅助分析和娱乐体验，不提供真实购彩、充值、提现或中奖承诺，请理性使用。

## 主要功能

### 双色球与大乐透

- 联网更新历史开奖号码，提供走势图、冷热号、遗漏值等统计分析
- 支持随机选号、条件选号、本地模型推荐和 DeepSeek AI 推荐
- 支持AI号码点评、模拟投注、开奖核对、投注记录与盈亏回顾
- 可授权定位并查询附近的彩票门店

### 原创刮刮乐

- 提供多款原创虚拟刮刮乐玩法
- 支持连续刮擦、票夹管理、中奖结算和历史战绩
- 采用本地持久化和幂等结算，避免重复扣券或重复派奖

### 动态像素养鸡场

- 鸡可以在像素养鸡场中自主行走、进食、饮水和互动
- 包含孵化、成长、产蛋、仓库、图鉴及环境布置系统
- 不同食物、饮水和装饰物会影响变化蛋主题的内部权重
- 支持离线时间结算，关闭应用后成长与产蛋进度仍可继续

## AI与数据能力

- 本地统计模型与AI推荐分工运行
- 针对双色球、大乐透的不同号码规则配置独立提示词
- 对AI返回结果进行结构化解析、号码范围校验、失败重试和结果缓存
- DeepSeek API Key由用户自行填写并保存在本机

## 账号与数据保护

- 支持注册、登录、修改密码、恢复码及可信设备找回
- 用户操作优先保存在本机，不因网络延迟阻塞正常使用
- 登录后自动将本地变化备份到云端
- 支持本机与云端数据自动合并、防缩减保护和历史恢复点
- 保障覆盖升级、换机或重新安装后的数据连续性

## 应用更新

- 支持自动检查和手动检查新版本
- 可在应用内直接下载新版APK并查看下载进度
- 下载完成后校验文件大小和SHA-256，随后进入Android安装页面
- 使用相同包名与签名覆盖安装，可保留原有应用数据

## 技术与质量保障

- Android、Capacitor、HTML、CSS、JavaScript
- 腾讯云CloudBase云函数、数据库与云存储
- DeepSeek API与Android原生能力接入
- 覆盖业务规则、数据迁移、弱网断网、账号切换和备份冲突测试
- 通过模拟器与Android真机持续验证触控、布局、性能和版本升级
